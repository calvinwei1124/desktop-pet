卡通桌面宠物

版本 1.1.0 · Electron 桌面应用

这是什么

一款常驻 macOS 屏幕的卡通桌面宠物：把喜欢的动画角色养在屏幕角落，陪你工作、提醒你休息。 5 位角色可选（机器猫 / 葫芦兄弟 / 齐天大圣 / 舒克和贝塔 / 邋遢大王），并可持续扩展更多伙伴。

主要功能

  • 多角色切换：右键菜单栏 Pet 随时更换宠物
  • 互动：单击宠物是"抚摸"，拖动可移动位置，双击打开设置
  • 🍅 番茄工作法：桌面倒计时，工作 / 短休 / 长休循环，阶段切换弹通知提醒你休息
  • 休息提醒：休息时宠物停下并冒出 💤 气泡，配合系统通知
  • 个性化：调节大小、透明度、点击穿透、所有桌面显示、开机自启

怎么用

  • 菜单栏点击 Pet 托盘 → 选角色 / 开始番茄钟 / 设置 / 退出
  • 双击屏幕上的宠物 → 打开设置面板，按需调整
  • 想开启番茄钟：设置里勾选「启用番茄钟」→ 点「开始 / 暂停」即可
提示：宠物默认"总在最前"。若不想挡住鼠标操作，可在设置里开启「点击穿透」。

技术 & 扩展

基于 Electron 构建。想新增角色，打开项目 characters.js 在数组末尾追加一个对象即可， 保存后重新 npm start，新角色会自动出现在列表与托盘菜单中。
